# Fotos

Sube aquí tus fotos con el nombre que usa cada JSON de `ejemplos/` (o cambia la ruta en el JSON).

- Vertical o cuadrada. El generador recorta al centro en 4:5 (1080x1350).
- Si falta una foto, sale un recuadro gris con el nombre: así puedes maquetar antes de tener todas.
- Conexión: fotos naturales, de tu vida, sin posar. Varias del mismo momento sirven (como un vídeo a trozos).
- Calentamiento: tú en tu contexto (trabajando, entrenando, entorno aspiracional).
- Venta: capturas y fotos de clientes, con su permiso.
